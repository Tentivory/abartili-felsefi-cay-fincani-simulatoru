# Abartılı Felsefi Çay Fincanı Simülatörü

## Bu Proje Nedir?

Bu, insanlık tarihinin en büyük bilimsel başarılarından biridir. Evet, yanlış okumadınız. **Abartılı Felsefi Çay Fincanı Simülatörü** ile artık sıradan bir çay fincanının içinde saklı olan derin felsefi anlamları keşfedebilirsiniz.

Bu simülatör, kuantum mekaniği, varoluşçuluk, Schopenhauer'in melankolisi ve Türk çay kültürünü birleştirerek size rastgele ama son derece ciddi felsefi çay sözleri üretir. Kod gerçekten çalışır. Deneyin. Hayatınız değişecek. Ya da değişmeyecek. Felsefi olarak her iki ihtimal de mümkün.

## Özellikler

- Çay fincanının ruhunu analiz eder
- Felsefi derinlikte çay sözleri üretir
- Hiçbir işe yaramaz ama çok ciddi görünür
- Python ile yazılmıştır çünkü neden olmasın
- Abartılı yorumlar içerir

## Kullanım

```bash
python3 cay_fincani_simulatoru.py
```

Çıktı örneği (gerçekten böyle çıkar):

> "Bu çay fincanı boş değildir. İçinde varoluşun tatlı acısı gizlidir. Schopenhauer bunu bilseydi çay içerdi."

## Kurulum

1. Bu repoyu klonlayın
2. Python 3 yüklü olsun (zaten vardır)
3. Çalıştırın
4. Hayatın anlamını sorgulayın
